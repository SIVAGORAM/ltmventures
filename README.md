# LTM Ventures India LLP

Official corporate website for **LTM Ventures India LLP**, featuring our flagship wealth management platform **[WealthyStep](https://www.wealthystep.com/)**.

## Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS v4
- **Language**: TypeScript
- **Icons**: Lucide React

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build production bundle
npm run build

# Start production server
npm run start
```
